# Устройство бота и инструкции для разработчика

**Аудитория:** студент или разработчик, который знакомится с проектом и должен безопасно менять его.

## Как устроен путь сообщения

```text
Пользователь Telegram
    -> Telegram Bot API (через aiogram)
    -> Dispatcher в main.py
    -> handlers/user_handlers.py
    -> services/services.py + lexicon/lexicon.py
    -> ответ и клавиатура
```

`handlers/other_handlers.py` предназначен для сообщений, которые не обработали специализированные маршруты. При подготовке документации в этом обработчике была замечена и исправлена ошибка сигнатуры; подробности см. в [диагностике](TROUBLESHOOTING.md).

## Ответственность модулей

| Файл | За что отвечает |
| --- | --- |
| `main.py` | Создаёт `Bot`, `Dispatcher`, регистрирует обработчики и запускает polling |
| `config_data/config.py` | Читает `BOT_TOKEN` из окружения через `environs` |
| `handlers/user_handlers.py` | Обрабатывает `/start`, `/help`, согласие/отказ и три игровых кнопки |
| `handlers/other_handlers.py` | Планируемая обработка нераспознанных сообщений |
| `services/services.py` | Случайный выбор бота и определение победителя |
| `keyboards/keyboars.py` | Формирует клавиатуру **Давай! / Не хочу!** и три игровых действия |
| `lexicon/lexicon.py` | Русскоязычные сообщения и подписи кнопок |

## Настройка

1. Установи зависимости по корневому README.
2. Возьми индивидуальный токен у @BotFather и запиши его **только в локальный** `.env`:
   ```dotenv
   BOT_TOKEN=PASTE_YOUR_OWN_TOKEN_HERE
   ```
3. Убедись, что `.env` указан в `.gitignore`.
4. Запусти `python main.py` из корня репозитория. В текущей версии путь к настройке рассчитывается относительно рабочего каталога.

## Изменения контента

Текст приветствия, кнопок и ответов хранится в словаре `lexicon_ru`. Если изменить подпись кнопки, обработчики в `user_handlers.py` сравнивают входящее сообщение с **тем же значением словаря** - отдельной замены строк в обработчиках не требуется.

После правки:
1. Проверь, что в словаре сохранены ключи `rock`, `paper`, `scissors`, `yes_button`, `no_button`.
2. Запусти `python -m unittest discover -s tests -v`.
3. Вручную проверь сценарии `/start`, `/help`, **Давай!**, три хода и **Не хочу!**.

## Интеграция с Telegram Bot API

Здесь нет собственного HTTP REST API. Проект использует `aiogram` как клиентскую библиотеку Telegram Bot API:

- входящие сообщения и callback-данные обрабатываются роутерами;
- ответы уходят через `message.answer(...)`;
- обновления бот получает через `Dispatcher.start_polling(bot)`;
- `Bot.delete_webhook(drop_pending_updates=True)` отключает webhook перед polling, поэтому ожидающие обновления могут быть удалены.

Для составления OpenAPI-спецификации собственного сервиса потребуется отдельный HTTP-сервер, которого в текущем проекте нет.
