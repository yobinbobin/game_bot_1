# Telegram Rock-Paper-Scissors Bot

Учебный Telegram-бот на Python и aiogram 3. Реализует игру «Камень, ножницы, бумага» через обычные кнопки: запуск, правила, выбор хода, результат и повторная игра.

> Проект учебный. Это не клиентский сервис и не интеграция с внутренними системами какой-либо компании.

## Быстрый старт

Нужны Python 3.10+ и токен бота от @BotFather. Для запуска из корня проекта:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate
python -m pip install -r requirements.txt
```

Создай локальный файл `.env` по шаблону `.env_example` и заполни переменную `BOT_TOKEN` собственным токеном. **Никогда не публикуй токен в GitHub.**

```bash
python main.py
```

После запуска найди своего бота в Telegram и отправь `/start`. Скрипт запускает long polling, поэтому терминал должен оставаться открытым. Для остановки нажми `Ctrl+C`.

**Проверка без Telegram-токена:** `python -m unittest discover -s tests -v` (проверяет правила игры).

## Что внутри

- `main.py`: запуск, подключение роутеров, polling.
- `handlers/`: обработка команд, действий пользователя и неизвестных сообщений.
- `keyboards/`: клавиатуры вариантов игры.
- `services/services.py`: выбор хода бота и определение победителя.
- `lexicon/`: пользовательские тексты и подписи кнопок.
- `config_data/`: чтение `BOT_TOKEN` из переменных окружения.
- `tests/`: автоматические тесты правил игры.

## Ограничения

- Бот хранит ход только в рамках текущего сообщения, постоянной БД нет.
- Отсутствуют мониторинг, CI, метрики и production-инфраструктура.
- Инструкции описывают текущее устройство репозитория; запуск через Telegram API требует действующего токена и сетевого доступа.
